| Program | Purpose | Download |
| --- | --- | --- |

| VirtualBox | Running isolated virtual machines | [Download VirtualBox](<https://www.virtualbox.org/wiki/Downloads>) |

### Installation

1. Download 7-Zip from its official website and install it.
2. Download and install WinRAR.
3. Download and install Oracle VirtualBox.
4. Configure an isolated virtual machine before conducting malware research.

**Important:** Never execute suspicious files directly on your main operating system. Use properly isolated virtual machines and appropriate security precautions.
